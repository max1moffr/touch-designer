# MAXMOTION

## Turn Movement Into Music

MAXMOTION is an interactive browser-based musical instrument that transforms hand gestures and movement into sound.

Using a webcam, MAXMOTION detects hand movements and finger positions, then maps them to musical chords and other controls. Instead of interacting with music through a traditional keyboard, MAXMOTION lets the user perform through movement.

---

## Features

- Real-time hand tracking
- Finger and gesture detection
- Gesture-based chord playing
- Webcam-based interaction
- Real-time audio synthesis
- Customizable chord mappings
- Customizable interface colors
- Performance recording
- Camera performance capture
- Gesture and chord event recording
- Browser-based experience
- No physical MIDI controller required
